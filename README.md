# sb-cli (Signbox CLI)

> **Ультимативный TUI-клиент для прокси и селективного сплит-туннелирования в Linux (Arch Linux)**  
> Эстетика и скорость **btop** + функционал и удобство **Happ** + точечная маршрутизация на базе **cgroups v2** и **nftables**.

---

## 🌟 Ключевые возможности

1. **Главный экран (в стиле Happ + btop):**
   - Управление подписками и списком серверов (VLESS, VMess, Shadowsocks, Trojan).
   - Подмена **User-Agent** (эмуляция `Happ/1.8.0`, `clash-meta`, `v2rayN`) для обхода блокировок со стороны провайдеров подписок.
   - Тестирование пинга (RTT в ms) до узлов прямо в интерфейсе.
   - Дашборд подключения с живым графиком скорости трафика (Braille-псевдографика в реальном времени).

2. **Двухпанельный монитор процессов (`P`):**
   - **Левая колонка:** Все процессы, которые по умолчанию идут через **VPN / Sing-box**.
   - **Правая колонка:** Процессы, перенесенные в **Direct (Прямое подключение)** в обход туннеля.
   - **Древовидная структура:** Отображение иерархии процессов (`[-]`, `├─`, `└─`) точь-в-точь как в btop.
   - **Сетевые метрики вместо Mem/CPU:** Количество открытых сокетов (`Conns`) и текущая скорость сети (`Down/Up`).
   - **Чистые имена Wine/Proton:** Вместо безликого `wine64-preloader` отображается чистое имя Windows-приложения (например, `cyberpunk2077.exe`).
   - **Умная фильтрация и группировка:**
     - `S` — скрыть системные демоны (`systemd`, `niri`, `polkitd` и др.).
     - `E` — объединить мультипоточные процессы/воркеры (например, несколько процессов `vesktop` объединяются в один).
     - `F` — живой поиск (`f _`), с переходом по `Tab` между колонками.

3. **Экран настроек (`` ` ``):**
   - Выбор User-Agent для подписок.
   - Переключение режима туннеля (`TUN - Sing-box TUN` / `System Proxy` / `Direct`).
   - Контроль защиты от DNS-утечек (DNS Leak Shield).

## ⌨️ Горячие клавиши (Hotkeys)

### Главный экран (Dashboard)
| Клавиша | Действие |
|---|---|
| `↑` / `k`, `↓` / `j` | Навигация по списку серверов |
| `c` / `Enter` | Подключиться / Отключиться от выбранного сервера |
| `t` | Быстрый тест пинга для всех узлов |
| `u` | Обновить активную подписку |
| `f` | Фильтр/поиск серверов по имени |
| `p` | **Перейти в экран управления процессами** |
| `` ` `` | **Перейти в настройки** |
| `q` | Выход из программы |

### Экран процессов (`P`)
| Клавиша | Действие | Описание |
|---|---|---|
| `↑` / `k`, `↓` / `j` | Навигация | Перемещение курсора по дереву процессов |
| `Tab` | Смена колонки | Переключение фокуса между **VPN** (слева) и **Direct** (справа) |
| `Enter` | 1 процесс | Перенести в Direct (или вернуть в VPN) **только этот 1 процесс** |
| `t` | Всё дерево | Перенести **родительский процесс и все его дочерние ветки** целиком |
| `s` | Системный фильтр | Скрыть/показать фоновые системные демоны |
| `e` | Схлопывание | Объединить потоки одного приложения (например, `vesktop`) в одну строку |
| `f` | Поиск | Активировать поиск (`f _`). `Tab` переключает колонку поиска |
| `q` / `Esc` | Назад | Возврат на главный экран |

## 🚀 Сборка и запуск на Arch Linux

### Зависимости
- Go (версии 1.22+)
- (Для боевого туннелирования): `sing-box`, `nftables`, `iproute2`

### Компиляция
```bash
make build
```
Бинарник будет собран в `./bin/sb-cli`.

### Запуск
```bash
./bin/sb-cli
# или через make:
make run
```
