# GEMINI.md — Контекст проекта signbox-cli

Документ содержит описание архитектуры, ключевые возможности, историю последних изменений и справочник для быстрой ориентации в кодовой базе `signbox-cli`.

---

## 1. Обзор проекта

**signbox-cli** — высокопроизводительный терминальный клиент (TUI) для [sing-box](https://github.com/SagerNet/sing-box) на Linux (Arch Linux).
Интерфейс спроектирован с эстетикой системного монитора **btop** и архитектурой разделения трафика по процессам в стиле **Happ**.

### Ключевой функционал
1. **Режимы туннелирования:**
   - **TUN:** Полный перехват трафика с маршрутизацией ядра через виртуальный сетевой интерфейс (`tun0`).
   - **System Proxy:** Локальный прокси `127.0.0.1:2080` (SOCKS5/HTTP).
   - **Direct:** Прямой сетевой доступ без туннеля.
2. **Process Split-Tunneling (Разделение процессов):**
   - Управление трафиком отдельных процессов через **cgroup v2** (`/sys/fs/cgroup/game-vpn`) и правила **nftables**.
   - Двухколоночный интерфейс: **VPN (Default / All Traffic)** и **Direct (Bypass / No VPN)**.
   - Поддержка иерархии процессов Windows-игр, запущенных через **Wine / Proton / Steam** (автоматический перенос всего дерева зависимых процессов в обход туннеля).
3. **GeoSite и GeoIP маршрутизация & Синхронизация баз:**
   - Загрузка свежих баз `geosite.db` (1881+ категорий) и `geoip.db` (238+ стран) из официальных GitHub-релизов в один клик (`[u]`).
   - Иерархическое меню правил: сначала выбор группы действий (**DIRECT**, **PROXY**, **BLOCK**), а затем переключение между двумя вкладками (**GeoSite** и **GeoIP**).
   - Модальный селектор категорий с мгновенным поиском по подстроке без сброса строки поиска, зеленой подсветкой активных правил (`✓`) и пакетным добавлением.
   - Совместимость с sing-box 1.13+: динамическая компиляция категорий в бинарные наборы правил (`.srs`) через `sing-box rule-set compile` без устаревших полей `geosite: [...]` / `geoip: [...]`.
   - Мгновенное применение правил на лету при активном VPN-соединении.
4. **Подписки и ноды:**
   - Поддержка протоколов `vless`, `trojan`, `vmess`, `shadowsocks`.
   - Парсинг подписок в форматах Base64 и Clash Meta YAML.
   - Подмена User-Agent (например, `Happ/1.8.0`, `clash-meta/1.18.0`) для обхода блокировок серверов подписок.
5. **Студия тем (Theme Studio):**
   - Настройка 9 элементов интерфейса прямо в TUI с помощью трех RGB-слайдеров (Red, Green, Blue).
   - Моментальный интерактивный предпросмотр (Live Preview) при каждом смещении ползунка.
   - Сохранение пользовательской палитры в конфиг `~/.config/sb-cli/config.json`.
6. **Фон и оформление:**
   - Гарантированный 100% сплошной черный фон (`#000000`) без просвечивания обоев терминала во всех экранах.

## 3. Недавние ключевые доработки

1. **Wine/Proton и Process Split-Tunneling:**
   - Реализована функция `toggleTreeBypass` и поддержка `wineserver`/`proton`/`.exe` процессов.
   - Добавлены алиасы названий для правильного сопоставления исполняемых файлов (например, `fsd-win64-shipping.exe` для Deep Rock Galactic).
2. **Навигация в Process View:**
   - Очистка поля поиска клавишей `Delete` / `Del`.
   - Автоматический выход из режима поиска при нажатии стрелок `Up`/`Down` с плавным переходом к выбору процессов.
   - Устранена паника `index out of range` при быстром сокращении списка процессов фильтром.
   - Зафиксирована позиция курсора при скролле колесиком мыши (скроллится список, а не курсор).
   - Реализовано естественное поведение скроллинга: при движении вверх сначала поднимается курсор, а список смещается только у границы окна.
3. **Theme Studio (Студия тем):**
   - Создана вкладка настройки тем (`ViewTheme`), доступная из Settings по клавише `t` или `Enter`.
   - Реализованы 3 слайдера RGB для любого из 9 цветов интерфейса.
   - Шаг регуляции: `←`/`→` (±1), `Shift+←/→` или `H`/`L` (±10). Переключение каналов: `Tab`, `↑`, `↓`.
   - Добавлен блок `Live Preview` для оценки сочетания цветов на лету.
   - Сохранение темы по клавише `s` в `~/.config/sb-cli/config.json`.
4. **Устранение прозрачности (100% Pure Black Background):**
   - Полностью ликвидирована проблема просвечивания обоев под текстом в терминалах с прозрачностью (Alacritty, Kitty, Wezterm и др.).
   - В функцию `paintSolidBlack` внедрен механизм перехвата кодов сброса: все `\x1b[0m`, `\x1b[m` и `\x1b[49m` моментально восстанавливают 24-битный цвет активного фона (`\x1b[48;2;R;G;Bm`).
   - Все текстовые блоки во всех представлениях явно обернуты в стили с привязкой к `ColorBg`.
   - Добавлен тест `TestAllViewsSolidBackgroundAndDimensions`, валидирующий геометрию и целостность фона для всех экранов.
5. **Исправление маршрутизации и Split-Tunneling (Direct Loop & Orphan Cleanup):**
   - Устранена петля маршрутизации: удалена ошибочная привязка `bind_interface` к `tun0` на `direct` outbound, возвращено связывание с физическим адаптером по умолчанию (`auto_detect_interface: true`).
   - `getDefaultInterface` переписан на чтение шлюза по умолчанию из `/proc/net/route` с фильтрацией виртуальных интерфейсов (`tun`, `tap`, `docker`, `virbr`, `vmnet`, `lo`).
   - Добавлены `killExistingCores`, `killOrphanedSingBox` и `waitForTunReleased` для гарантированного закрытия зависших демонов и освобождения `tun0` при старте и обновлении правил.
   - Устранено молчаливое подавление ошибки `TUNSETIFF: device or resource busy`: добавлен автоматический сброс старых процессов и повторный запуск sing-box с передачей статуса в TUI.
6. **GeoSite & GeoIP Rules Manager и Database Sync:**
   - Разработан пакет `pkg/geo/manager.go` для работы с геобазами (`~/.config/sb-cli/geo/`).
   - Реализована загрузка актуальных баз из GitHub-релизов через клавишу `u` в фоновом потоке Bubble Tea (`tea.Cmd`).
   - Создан экран `ViewGeoRules` с таблицей настроенных правил и модальным селектором категорий.
   - Поддерживаются действия `DIRECT`, `PROXY`, `BLOCK` с визуальными бейджами.
   - Преодолено ограничение sing-box 1.13+ (удаление `geosite:`/`geoip:`): категории автоматически компилируются в бинарные файлы `.srs` (`rules/<tag>.srs`), регистрируются в `route.rule_set` и привязываются в строгом приоритетном порядке (Block -> Direct -> Proxy).
   - Правила сохраняются в `~/.config/sb-cli/config.json` и автоматически перезагружаются в sing-box на лету.
7. **Сохранение поиска и зеленая подсветка правил в Geo Picker:**
   - При добавлении правила по клавише `Enter` селектор больше не закрывается, а поисковый запрос не сбрасывается.
   - Все уже добавленные в правила категории мгновенно подсвечиваются ярким зеленым цветом (`ColorSuccess`), галочкой `✓` и бейджем текущего действия (`[DIRECT]`, `[PROXY]`, `[BLOCK]`).
   - Повторное нажатие `Enter` на уже выбранном правиле обновляет или циклически переключает его действие.
   - Завершение добавления и возврат к таблице правил выполняется по клавише `Esc` (или `q` при пустой поисковой строке).
8. **100% безопасное завершение работы и окно подтверждения выхода:**
   - При нажатии `Ctrl+C` из любого места программы или `q` с главного экрана отображается стилизованное модальное окно подтверждения выхода (`Confirm Exit`).
   - Для выхода требуется подтвердить действие клавишами `y` или `Enter` (отмена — `n`, `Esc` или `q`).
   - Повторное нажатие `Ctrl+C` при открытом диалоге выполняет мгновенный принудительный выход.
   - Корректное завершение включает остановку процессов sing-box/xray, ожидание освобождения интерфейса `tun0` ядром Linux, а также обработку системных сигналов `SIGINT`, `SIGTERM`, `SIGHUP`.
9. **Двухуровневая иерархия Geo-правил (Action Menu → GeoSite/GeoIP Tabs → Add Picker):**
   - **Уровень 1 (Action Menu):** Стартовый экран Geo-правил разделен на 3 группы действий: `[1] DIRECT (Bypass VPN)`, `[2] PROXY (Route via VPN)`, `[3] BLOCK (Drop Traffic)` с подробным описанием и счетчиками активных категорий и стран.
   - **Уровень 2 (Action View):** Внутри выбранного действия доступны две вкладки `GeoSite (Domains)` и `GeoIP (Country IPs)` (`[Tab]` или `[1]`/`[2]`) с таблицей активных правил, удалением (`[d]`/`[Del]`) и перемещением между группами (`[Space]`).
   - **Уровень 3 (Add Picker Modal):** Селектор категорий с поиском без сброса строки, яркой зеленой подсветкой активных правил (`✓ [ACTION]`), возможностью пакетного добавления по `Enter` и возвратом в таблицу по `Esc`.
   - **Иерархическая навигация:** Клавиши `q`/`Esc` осуществляют подъем по уровням: Picker (L3) → Action View (L2) → Action Menu (L1) → Settings.
10. **Отображение сохраненных (Offline) процессов в Bypass:**
   - Все добавленные в исключения процессы из `bypass_names` (например, `cs2.exe`, `gamescope-wl`) остаются в правой колонке Direct (Bypass) даже после их закрытия.
   - Оффлайн-процессы помечаются статусом `[saved]` и PID `  -   `, отображаются в приглушенном цвете `ColorMuted`, и могут быть удалены из исключений по клавише `Enter`.
   - При повторном запуске программы оффлайн-заглушка мгновенно заменяется живым процессом с реальным PID, сокетами и сетевой скоростью.
11. **Корректное сворачивание копий процессов (`e` / Collapse):**
   - Устранена ошибка, из-за которой цепочка дочерних процессов (например, 7 копий `cs2.exe`) не схлопывалась, а выводила каждую строку с нисходящим счетчиком `(6)`, `(5)`, `(4)`...
   - Реализована функция `collapseSubtree`: одинаковые процессы схлопываются в одну аккуратную строку `[+] PID Program (N)` с точным подсчетом общего количества копий `(N)` и суммированием открытых сетевых сокетов.
   - При разворачивании (`e`) снова отображается детальное дерево всех процессов.
12. **Универсальный парсер подписок (Remnawave JSON, HWID, Clash YAML, Base64, локальные файлы):**
   - **Remnawave & HWID:** Добавлена автоматическая генерация и передача заголовков `X-HWID` и `HWID` на основе `/etc/machine-id` (или `/var/lib/dbus/machine-id` / persistent UUID). Серверы Remnawave (например, Panda VPN) теперь отдают полный список серверов вместо фиктивных заглушек.
   - **Устранение лимита 64KB:** Чтение тела HTTP-ответа переведено с `bufio.Scanner` на `io.ReadAll`, что устранило отсечение больших JSON-подписок (более 64 КБ).
   - **Remnawave Load Balancers & Profiles:** Поддержка парсинга JSON-массивов с готовыми профилями Xray. Конфигурация балансировщика сохраняется и исполняется ядром Xray с автоматической настройкой SOCKS на `127.0.0.1:2080` и `mark: 255`. Все IP-адреса серверов балансировщика автоматически исключаются из маршрутизации `tun0` для защиты от сетевых петель.
   - **Clash Meta YAML:** Интегрирован парсер `yaml.v3` для извлечения нод VLESS (Reality, flow), Shadowsocks, Trojan, VMess, Hysteria2 из секции `proxies:`.
   - **Импорт локальных файлов:** В диалоге добавления подписки (`[a]`) поддерживается ввод пути к локальному файлу (JSON, YAML, TXT), прямого URI или вставка «сырого» текста/JSON.
   - **Явная индикация ошибок:** Полностью ликвидировано тихое игнорирование ошибок; ошибки провайдеров и статусы HTTP выводятся в красный статусный баннер TUI.
13. **Стиль курсора и скроллинг серверов в стиле btop (Main View):**
   - Градиентная зеленая подсветка расстояния от курсора (`GetGreenGradient(dist)`).
   - Выделение активной строки на всю ширину (`ColorSelection`), яркий акцент названия (`#69ff94`) и индикатор `●`.
   - Вертикальный скроллбар (`█` и `│`) и счетчик в нижней границе `[selected/total]` (например, `[1/90]`).
   - Плавный скроллинг колесиком мыши без смещения курсора, естественный подъем курсора и сдвиг окна.
14. **Универсальная поддержка раскладок клавиатуры (Layout-Agnostic Hotkeys):**
   - Полная поддержка русской (и украинской) раскладки: хоткеи (`с` -> `c`, `з` -> `p`, `ё` -> `` ` ``, `й` -> `q`, `а` -> `a`, `е` -> `t` и др.) работают мгновенно без переключения раскладки на английскую.
   - Поля ввода текста (поиск, добавление подписки, Custom User-Agent) принимают нативные символы любого языка в UTF-8.
15. **Фоновый режим работы (Background Daemon Mode) и systemd-автозапуск:**
   - VPN-туннель продолжает работать в фоне при выходе из TUI (процессы `sing-box` и `xray` отвязаны от терминала через `Setpgid: true`).
   - Добавлены CLI-команды:
     - `sb-cli --start` (или `--daemon`) — фоновый запуск VPN без интерфейса.
     - `sb-cli --stop` — остановка фонового туннеля и освобождение сетевых адаптеров.
     - `sb-cli --status` — проверка статуса подключения и активной ноды.
     - `sb-cli --install-service` — установка `systemd --user` сервиса (`signbox-vpn.service`) для автозапуска при загрузке.
     - `sb-cli --uninstall-service` — удаление пользовательского сервиса systemd.
   - В окне подтверждения выхода (`Confirm Exit`) при активном VPN туннеле предложен выбор:
     - `[Enter / y]` — Оставить VPN в фоне и выйти из TUI.
     - `[d]` — Отключить VPN и завершить работу.
     - `[Esc / n]` — Отмена выхода.
16. **Пользовательский User-Agent (Custom UA) в Настройках:**
   - Возможность указания произвольной строки User-Agent прямо через TUI с сохранением в конфигурацию.
17. **Сворачивание и разворачивание подписок (`e` / `E` / `Space` / `Enter`):**
   - Иерархическое отображение подписок и серверов в стиле btop: каждая подписка оформлена стильной строкой заголовка `▼ [Название] (N серверов) Трафик`.
   - Сворачивание отдельной подписки клавишей `e`, `Space` или `Enter` на строке группы (скрывает все ее серверы, показывая `▶ [Название] (N) [collapsed]`).
   - Нажатие `e` на любом сервере внутри подписки мгновенно схлопывает ее и переносит курсор на заголовок группы.
   - Клавиша `E` (Shift+E) выполняет мгновенное переключение: свернуть все / развернуть все подписки.
   - При активном поиске (`f`) подписки автоматически раскрываются для отображения найденных результатов.
18. **Исправление таймера подключения при перезаходе в TUI:**
   - Устранена ошибка отображения аномального аптайма (`2562047h47m16s`): движок фиксирует точное время старта в файле `/tmp/sb-cli/connected_at` и восстанавливает его через `engine.GetConnectedAt()`.
   - Добавлена функция `formatUptime`, форматирующая время в аккуратный вид (`02m 45s`, `01h 15m 30s`) с идеальным центрированием внутри статусного виджета.
   - Внедрена защитная самодиагностика: если при активном VPN `ConnectedAt` оказывается нулевым или невалидным, он автоматически подтягивается из ядра sing-box.
19. **Редизайн диалога выхода (устранение вырвиглазных цветов):**
   - Полностью удалены кричащие неоновые заливки кнопок.
   - Диалог выхода переведен на элегантную эстетику системных терминалов: чистый черный фон (`#000000`), лаконичные подсвеченные клавиши `[Enter/y]`, `[d]`, `[Esc]` и спокойные описания действий белым цветом.
20. **Экран логов (Logs Viewer) по клавише `L` с 5 вкладками:**
   - Полноэкранный просмотрщик логов по клавише `L` / `l` / `Д` / `д` из любого экрана.
   - Цикличное переключение вкладок по клавише `Tab` (а также `Shift+Tab`, `1..5`, `Left/Right`):
     1. `main log` — системные события, жизненный цикл клиента, смена режимов, подключения/отключения, обновления bypass и geo (`/tmp/sb-cli/main.log`).
     2. `core log` — подробные логи сетевого ядра Xray (`/tmp/sb-cli/xray.log`).
     3. `tunnel log` — логи sing-box TUN-маршрутизатора (`/tmp/sb-cli/sing-box.log`).
     4. `subscribtion log` — журнал запросов подписок, спуфинга HWID/User-Agent, подсчета нод и трафика (`/tmp/sb-cli/subscription.log`).
     5. `daemon log` — логи системной службы systemd (`journalctl --user`) и фонового демона (`/tmp/sb-cli/daemon.log`).
   - Поддержка auto-follow (автопрокрутка к новым логам на лету `[f]`), постраничная навигация (`PgUp/PgDn`, `Home/End`, колесико мыши), очистка текущего лога (`[c]`) и принудительное обновление (`[r]`).
   - Синтаксическая подсветка уровней (`[INFO]`, `[WARN]`, `[ERROR]`, `inbound/tun`, `outbound/direct`, `outbound/socks`) и 100% сплошной черный фон (`#000000`).
21. **Исправление автозапуска systemd и подключения к последнему серверу:**
   - **Устранение ошибки поиска бинарников:** В `pkg/core/engine.go` внедрена функция `resolveBinary`, которая определяет путь к `sing-box` и `xray` относительно исполняемого файла `sb-cli` (`os.Executable()`), что устранило падение systemd на старте с ошибкой `fork/exec ./bin/sing-box: no such file or directory`.
   - **Коррекция юнита systemd:** В файл службы `~/.config/systemd/user/signbox-vpn.service` явно прописаны `WorkingDirectory` (каталог проекта), переменная `Environment="PATH=..."` и таргет `After=network-online.target default.target`.
   - **Защита от ложного `IsRunning`:** Устранена проблема, когда старый сокет или остаточный `tun0` вызывал ложный статус `VPN tunnel is already running`. Теперь выполняется строгая валидация процесса в `/proc/<pid>/comm`.
   - **Стабилизация сети при загрузке:** В CLI-команду `sb-cli --start` добавлен цикл повторных попыток (до 3 раз с паузой 2 секунды) для ожидания готовности сетевых интерфейсов ядра Linux при старте системы.
   - **Автоматическое позиционирование курсора на последнем сервере:** При открытии TUI курсор (`❯`) и окно скроллинга автоматически устанавливаются на последнем подключенном/активном сервере (`state.ActiveNode`).
   - **Изоляция тестовых конфигов:** Внедрена переменная `SB_CONFIG_PATH`, защищающая реальный конфигурационный файл `~/.config/sb-cli/config.json` от случайной перезаписи во время прогона тестов.
22. **Индивидуальный роутинг подписок (Per-Subscription GeoSite/GeoIP Routing Profiles):**
   - **Иерархия 4 уровней управления правилами:**
     - **Уровень 0 (Profile Selection):** Выбор профиля маршрутизации: `[0] Global / Default Rules` или конкретная подписка `[1..N] <Название подписки>`. Профили визуально разделены, снабжены счетчиками категорий/стран и управляются курсором выбора.
     - **Уровень 1 (Action Menu):** Выбор группы действий (`DIRECT`, `PROXY`, `BLOCK`) для выбранного профиля с индикацией активного профиля в шапке.
     - **Уровень 2 (Action View):** Две вкладки `GeoSite (Domains)` и `GeoIP (Country IPs)` для выбранного профиля. Удаление правил выполняется клавишей `[Del] / [Delete]` (а также `[d]`), переключение действия — `[Space]`.
     - **Уровень 3 (Add Picker Modal):** Поиск по базе и добавление правил в текущий профиль без закрытия окна и сброса поисковой строки.
     - **Иерархический выход:** Клавиши `[q] / [Esc]` последовательно возвращают на уровень выше: L3 (Picker) → L2 (Action View) → L1 (Action Menu) → L0 (Profile List) → Settings.
   - **Парсинг правил из подписок (Clash YAML & Sing-box/Remnawave JSON):**
     - Автоматическое извлечение правил `GEOSITE` и `GEOIP` из секции `rules:` в Clash Meta YAML (с сопоставлением `DIRECT`, `REJECT`/`BLOCK`, `Proxy`).
     - Извлечение правил из `route.rules` / `routing.rules` в Sing-box JSON / Remnawave конфигурациях (поддержка `geosite: [...]`, `geoip: [...]`, `rule_set: ["geosite-...", "geoip-..."]`).
     - Подписки без правил в источнике инициализируются с пустым роутингом и автоматически наследуют глобальные правила.
   - **Прозрачность и редактирование:** Любые правила подписки можно посмотреть и отредактировать прямо в TUI.
   - **Применение при подключении (`model.ResolveGeoRules`):** При подключении к ноде ядро использует правила ее подписки (если они заданы), либо автоматически откатывается на глобальные правила `Global / Default Rules`.
23. **Удаление и сортировка подписок (Delete & Reorder Subscriptions):**
   - **Сортировка/перемещение выше и ниже:**
     - Хоткеи: `J` / `Shift+↓` / `Ctrl+↓` / `]` / `>` (переместить выбранную подписку вниз), `K` / `Shift+↑` / `Ctrl+↑` / `[` / `<` (переместить выбранную подписку вверх).
     - Полная поддержка русской раскладки клавиатуры: `О` (вниз) и `Л` (вверх).
     - Сортировка доступна как в главном списке серверов (`ViewMain`), так и в селекторе профилей Уровня 0 в Geo-правилах (`ViewGeoRules`).
     - Автоматическое сохранение порядка подписок в `~/.config/sb-cli/config.json`.
     - Умное слежение курсора: фокус остается на перемещаемой группе подписки с автопрокруткой списка.
   - **Безопасное удаление подписок:**
     - Хоткеи: `d` / `D` / `Delete` / `Del`.
     - Защита от случайного удаления: нажатие `d` на строке отдельного сервера выводит предупреждающую подсказку (`Tip: Press [e] to focus header, then [d] to delete...`). Для быстрого удаления со строки сервера поддерживается `Shift+D` или клавиша `Del`.
     - Нажатие `d` или `Del` на строке заголовка подписки сразу удаляет подписку.
     - Безопасное отключение: если активное VPN-соединение использовало сервер из удаляемой подписки, туннель корректно останавливается, `ActiveNode` очищается, а курсор позиционируется на ближайшем элементе.
     - На Уровне 0 в Geo-правилах клавиша `d`/`Del` сбрасывает индивидуальные правила подписки (возврат к `Global`), либо удаляет подписку, если ее правила уже очищены.
24. **Парсинг сырых доменов и IP из подписок Remnawave/Xray и пакетная компиляция:**
   - **Поддержка сырых списков `domain` и `ip`:** Расширен `ParseJSONRules` для автоматического извлечения маршрутизации из полей `domain`, `domains`, `domain_suffix`, `domain_keyword`, `ip`, `ips`, `ip_cidr` в профилях Remnawave, Xray и V2Ray. Корректно очищаются префиксы `geosite:`, `domain:`, `full:`, `geoip:`, извлекая как именованные теги, так и сырые домены и CIDR-подсети.
   - **Пакетная компиляция кастомных правил (`custom-<action>.srs`):** В `pkg/geo/manager.go` внедрена функция `compileCustomBatchRuleSet`: все произвольные домены и IP-диапазоны группируются по действию (`DIRECT`, `PROXY`, `BLOCK`) и компилируются sing-box в оптимизированные бинарные rule-set'ы (`custom-direct.srs` и др.) за 10–15 миллисекунд.
   - **Скроллинг и пагинация в таблице правил (Action View):** Внедрен скроллинг (`geoRuleScroll`, `visRows`, `Showing X..Y of Z rules`) с навигацией по `↑`/`↓`, `PgUp`, `PgDn`, `Home`, `End`, позволяющий комфортно просматривать и редактировать таблицы с тысячами правил без переполнения экрана терминала.
   - **Мгновенное автовосстановление правил из `raw_json`:** При запуске клиента правила для существующих подписок автоматически считываются из сохраненных сырых JSON-профилей серверов и сохраняются в `~/.config/sb-cli/config.json`.
25. **Реорганизация Настроек (App Settings / Tunnel Settings) и гибкая настройка Fragmentation, Mux, IP Type, Advanced DNS/Sniffing:**
   - **Структурированное разделение настроек на два смысловых блока:**
     - `[1] APP SETTINGS`: Theme Studio, Автозапуск при загрузке системы (systemd user service), Subscription User-Agent (быстрый выбор популярных клиентов + ручной ввод произвольного UA).
     - `[2] TUNNEL SETTINGS`: Routing Mode (TUN/System Proxy/Direct), Preferred IP Type, GeoSite/GeoIP Routing Profiles, TLS Fragmentation Studio, TCP/UDP Multiplexing (Mux) Studio, и подраздел Advanced Settings.
   - **Предпочитаемый тип IP (Preferred IP Type):**
     - Выбор стратегии разрешения IP: `prefer_ipv4` (Default), `prefer_ipv6`, `ipv4_only`, `ipv6_only` по клавише `Enter` или `Space`.
     - Для sing-box устанавливает глобальный `dns.strategy`. Для Xray транслируется в `domainStrategy`: `UseIPv4v6`, `UseIPv6v4`, `UseIPv4`, `UseIPv6`.
   - **Студия TLS Fragmentation (TLS Fragmentation Studio):**
     - Продвинутая фрагментация пакетов TLS Client Hello для обхода DPI-блокировок и замедлений.
     - Интерактивный TUI-экран: переключение пресетов по `Enter`/`Space` для Packets (`tlshello`, `1-3`, `1-5`), Length (`100-200`, `50-100`, `10-30`), Interval (`10-20`, `5-10`, `1-5`), ручной ввод произвольных значений (`[e]`), сброс к рекомендованным дефолтам (`[r]`), и Live JSON Preview.
     - Интеграция в движок Xray: динамическая генерация `freedom` outbound с тегом `fragment` и связывание прокси-нод через `streamSettings.sockopt.dialerProxy = "fragment"`.
   - **Студия мультиплексирования соединений (Mux Studio):**
     - Интерактивное управление мультиплексированием соединений TCP и UDP.
     - Плавные визуальные слайдеры Concurrency (1..128) и XUDP Concurrency (1..128) с шагом `←`/`→` (±1), `H`/`L` или `[`/`]` (±8).
     - Переключение политики XUDP для UDP 443 (`reject`, `allow`, `skip`).
     - Live JSON Preview конфигурации Mux и сброс к рекомендованным дефолтам (`[r]`).
   - **Расширенные настройки туннеля (Advanced Settings):**
     - 6 гибких параметров:
       1. `Use local DNS` (Off/On) — локальный DNS для прямых подключений без риска утечек в туннель.
       2. `Use DNS from JSON` (Off/On) — приоритет DNS-серверов из импортированных конфигураций.
       3. `Enable Resolve Server` (On/Off) — выделенный безопасный сервер разрешения DNS.
       4. `DNS IP for resolve Server` (инлайн-редактирование IP, default: `1.1.1.1`).
       5. `DNS domain for resolve Server` (инлайн-редактирование DoH URL, default: `https://1.1.1.1/dns-query`).
       6. `Enable sniffing` (On/Off) — перехват HTTP, TLS (SNI) и QUIC доменов для прозрачной маршрутизации.
   - **Горячая перезагрузка (Live Reload on the fly):** Любое изменение параметров туннеля (Mux, Fragmentation, IP Strategy, DNS, Sniffing) моментально сохраняется в `~/.config/sb-cli/config.json` и на лету перезагружает работающие ядра `sing-box` / `xray` без разрыва сессии пользователя.

## 4. Справочник команд и запуск

### Сборка и тесты
```bash
# Запуск всех тестов
go test -v ./...

# Сборка бинарника клиента
go build -o ./bin/sb-cli ./cmd/sb-cli/main.go

# Запуск интерактивного TUI
./bin/sb-cli

# Фоновое управление VPN (Daemon mode)
./bin/sb-cli --start              # Запуск VPN в фоне
./bin/sb-cli --status             # Статус подключения
./bin/sb-cli --stop               # Остановка фонового VPN

# Управление автозапуском через systemd
./bin/sb-cli --install-service    # Включить автозапуск при входе
./bin/sb-cli --uninstall-service  # Отключить автозапуск
```

### Системные привилегии
- Для работы TUN без запуска всего клиента от `root`:
  ```bash
  sudo setcap cap_net_admin=+ep ./bin/sing-box
  ```
- Для split-tunneling (cgroup v2) требуется доступ к `/sys/fs/cgroup/game-vpn`. Приложение автоматически проверяет и монтирует cgroup при наличии прав.

## 5. Горячие клавиши (Hotkeys)

*Все хоткеи работают как на английской, так и на русской раскладке клавиатуры.*

- `q` / `й` — Назад (из подменю) / Окно подтверждения выхода (с главного экрана)

- При активном VPN:
  - `Enter` / `y` / `н` — Оставить VPN работать в фоновом режиме и выйти
  - `d` / `в` — Отключить VPN и выйти
  - `n` / `т` / `Esc` — Отмена выхода
- При отключенном VPN:
  - `Enter` / `y` / `н` — Подтвердить выход
  - `n` / `т` / `Esc` — Отмена выхода

- `↑` / `↓` — Выбор элемента палитры
- `Enter` — Активировать ползунки RGB для выбранного цвета
- `←` / `→` — Изменить значение слайдера на ±1
- `H` / `L` или `Shift+←/→` — Изменить значение слайдера на ±10
- `Tab` / `↑` / `↓` — Переключение между слайдерами Red, Green, Blue
- `r` — Сброс цвета элемента к значению по умолчанию
- `s` — Сохранить тему на диск в конфиг
- `Esc` или `Enter` (в режиме слайдеров) — Завершить редактирование цвета

### Logs Viewer (Экран логов)
- `Tab` — Цикличное переключение вкладок (`main log` → `core log` → `tunnel log` → `subscribtion log` → `daemon log`)
- `Shift+Tab` / `Left` / `h` — Переключение вкладки назад
- `1` / `2` / `3` / `4` / `5` — Быстрый переход на вкладку 1..5
- `↑` / `↓` (`k` / `j`) — Построчная прокрутка логов (отключает автопрокрутку)
- `PgUp` / `PgDn` — Прокрутка на страницу вверх / вниз
- `Home` / `g` — Переход в самое начало лога
- `End` / `G` — Переход в самый конец лога (включает автопрокрутку)
- `f` — Включить / выключить автопрокрутку (Auto-follow live stream)
- `r` — Принудительно перечитать текущий лог с диска
- `c` — Очистить текущий лог
- `q` / `Esc` / `L` — Назад в главный экран (Dashboard)
